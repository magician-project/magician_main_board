# KiCad Boards

This directory holds the KiCad projects for the Magician sensing PCBs, organized by hardware revision:

- [`v1/`](v1/README.md) — the original Magician Main Board (Arduino Nano, 3x VL53L0X, 74HC595 shift register). Superseded, kept for reference.
- [`v4/`](v4/README.md) — **MagicianCam4**, the current board (Raspberry Pi Pico 2, VL53L5CX multizone ToF sensor, MCP23018 I/O expander).
